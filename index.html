平成マネー YouTube Publisher

このアプリは、YouTubeチャンネル「平成マネー」（@heiseimoney）の運営者が、自分のチャンネルに動画をアップロード・予約公開するためだけに使う個人用ツールです。一般の利用者向けの公開サービスではありません。

プライバシーポリシー

制定日：2026年11月26日

取得する情報：GoogleのOAuth認証を通じて、YouTube Data APIで運営者本人のチャンネル情報（チャンネルID・チャンネル名）と、動画のアップロード・公開設定・再生リスト管理に必要な権限を取得します。

利用目的：運営者本人のチャンネルへの動画のアップロード、予約公開、再生リスト追加、投稿先チャンネルの確認のためだけに使用します。

保存と第三者提供：認証トークンは運営者のPC内にのみ保存し、外部のサーバーへ送信・保存しません。取得した情報を第三者に提供・販売しません。

Google API：Google APIから受け取った情報の使用は、Limited Use の要件を含む Google API Services User Data Policy に従います。

アクセス権の取り消し：Googleアカウントの設定からいつでも取り消せます。

利用規約

本ツールは運営者本人が自分のYouTubeチャンネルを管理するための個人用ツールで、運営者以外の利用は想定していません。利用はYouTube利用規約およびGoogleの利用規約に従います。
